# Math Formatting Rule

- The chat interface UI does not render LaTeX math syntax.
- **NEVER** use LaTeX delimiters such as `$`, `$$`, `\(`, `\[`, or LaTeX commands like `\frac`, `\sqrt`, `\approx`, `\mathbb`, `\sum` in your chat responses.
- **ALWAYS** use plain text and Unicode symbols for mathematical expressions, formulas, and variables.
  - Use Unicode superscripts and subscripts (e.g., x², x₁, rᵈ).
  - Use standard mathematical symbols: √, ≈, ≤, ≥, ±, ×, ÷, ·, ∝, ∞, ∑, ∫, ∈.
  - Write fractions inline as simple divisions (e.g., 1/d, 1/√d, (0.99)ᵈ / (1.0)ᵈ).
  - Format multi-line calculations using clean indented text, bullet points, or code blocks (`text` or `python`) if necessary.
