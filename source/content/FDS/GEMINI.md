# Workspace Rules

## Math and Formula Formatting
- The chat interface UI does not render LaTeX math syntax.
- **NEVER** use LaTeX math delimiters (`$`, `$$`) or LaTeX markup (`\frac`, `\sqrt`, `\mathbb`, etc.) in responses.
- **ALWAYS** write math using plain text and Unicode characters (e.g., √, ≈, ≤, ≥, ², ³, ₁, ₂, ·, ×, ÷, ∑).
